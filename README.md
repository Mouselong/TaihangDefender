# 太行卫士：农大护田战

一款基于 Java Swing 开发的五路塔防打字游戏，融合农业主题与英语学习元素。

---

## 🎮 游戏玩法

游戏玩法方面，我们项目通过打字来获取能量，当拥有足够能量时可以购买农大特色的防御塔来构建防线，防御塔会自动攻击经过的害虫并阻止它们前进，每击败一只害虫都会获得对应分数，每清空一波害虫后可从三种增益中选择一种强化防线，如果害虫突破防线到达终点就会扣除一点生命值，生命值归零时游戏结束。

## ⌨️ 操作说明

| 操作 | 功能 |
|------|------|
| 1 / 2 / 3 | 快速切换塔型 |
| 鼠标左键 | 放置防御塔 |
| 鼠标右键 | 打开塔购买菜单 |
| U | 撤销最近放置的塔（3秒窗口） |
| Esc | 取消拖拽 / 回到输入框 |
| ? | 显示帮助信息 |

## 🎲 Roguelike增益系统

每波结束后可从20+种增益中随机选择3种，包括：

- **永久增益**：塔伤害/射程/攻速提升、能量上限增加、暴击率提升
- **即时效果**：恢复生命、闪电打击全体敌人、获得能量
- **临时增益**：科技助农强化、害虫减速、毒素光环

## 📝 核心特性

1. **打字能量系统**：输入单词获得能量，支持首字母锁定
2. **对象池优化**：子弹和敌人使用对象池减少GC压力
3. **便携字体支持**：内嵌Noto Sans CJK字体确保中文显示
4. **音效系统**：支持背景音乐和多种游戏音效
5. **存档功能**：支持多级撤销操作（3秒窗口）
