害虫图鉴图片说明
==================

将您的害虫图片放入此目录，文件命名需与以下列表匹配：

需要的图片文件名：
1. 东亚飞蝗.jpg (或 东亚飞蝗 .jpg)
2. 地老虎.jpg
3. 小菜蛾.jpg (或 小菜蛾 .jpg)
4. 桃蚜.jpg
5. 玉米螟.jpg
6. 金针虫.jpg

图片建议规格：
- 格式：JPG 或 PNG
- 尺寸：建议宽度 500-800 像素
- 如果没有图片，程序会自动显示美观的占位图

打包说明：
- 确保 resources/pests 目录在编译时被复制到 out 目录
- 使用项目根目录的 build-and-package.ps1 脚本打包时会自动包含这些图片
