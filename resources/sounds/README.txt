音效文件说明
=============

请将下列 WAV 格式的音效文件放入此文件夹：

必需文件：
- bgm.wav          - 背景音乐（循环播放）

音效文件：
- place_tower.wav  - 放置塔
- tower_shoot.wav  - 塔射击
- enemy_die.wav    - 敌人死亡
- word_success.wav - 打字成功
- wave_start.wav   - 波次开始
- wave_complete.wav - 波次结束
- game_win.wav     - 游戏胜利
- game_lose.wav    - 游戏失败
- perk_choice.wav  - 选择增益

注意事项：
1. 推荐使用 16-bit PCM WAV 格式，采样率 44100Hz 或 48000Hz
2. 音效时长不要太长（建议单个音效不超过5秒）
3. 如果没有音效文件，游戏会使用系统蜂鸣作为临时替代
4. 可以使用免费的音效库（如 freesound.org、zapsplat.com）下载合适的音效
